# ♟️ CHESSWORLD.GAMES — Chess-Inspired Game Collection

Welcome to the beginnings of the ultimate collection of chess-related games playable on **CHESSWORLD.GAMES**, a platform for experimenting with chess-inspired mechanics and original strategy ideas.

These games are not traditional chess clones. Instead, they explore what happens when you change one rule, one piece, or one objective — and build a whole game around it.

---

## 🎮 What this repository is

This repo contains small, self-contained games built entirely for the CHESSWORLD.GAMES platform.

Each game is:

- Fully playable in the browser
- Based on chess in some way (movement, structure, or strategy)
- Designed with a unique twist or rule change
- Built to be simple, readable, and easy to review
- Completely independent (no shared dependencies or backend)

---

## 🚀 Purpose

This repository is part of a submission process for CHESSWORLD.GAMES and represents my exploration of game design through constrained systems.

The goal is to show how simple rule changes in a familiar system like chess can create entirely new and interesting gameplay experiences.
