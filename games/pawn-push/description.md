# Pawn Push

A stripped-down two-player strategy game played on a 6x6 board using only chess pawns. No queens, no knights, no castles — just the humble pawn doing its job.

The tension of Pawn Push mirrors real chess endgame pawn races. Every move matters. Every capture is a gamble. First pawn to reach the other side wins.

Built as a demonstration of the CHESSWORLD.GAMES platform module structure.
