## Rules

- Move the bishop from the starting square to the star goal
- The bishop moves diagonally only — any number of squares in a diagonal direction
- Dark hatched squares are walls — the bishop cannot pass through or land on them
- If the bishop gets stuck with no valid moves, the level resets
- Try to reach the goal in par moves or fewer

## Controls

| Action | How |
|--------|-----|
| Move bishop | Click any highlighted square |
| Restart level | Click the Restart button |
| Skip level | Click the Skip button |

## Scoring

| Result | Description |
|--------|-------------|
| At or under par | Perfect — well done |
| 1–2 over par | Good — room to improve |
| 3+ over par | Try again for a better path |
